# Kamna Tour & Travel Android

Test Android app for Kamna Tour & Travel, Rewa, Madhya Pradesh.

## Included
- Cars: Swift Dzire, Hyundai Creta, Toyota Innova Crysta, Maruti Ertiga, Kia 7 Seater, Bolero Neo, Force Traveller / Urbania, Tempo Traveller, Tata Sierra
- Rewa local sightseeing: Keoti Falls, Govindgarh Fort, White Tiger Safari Mukundpur, Rani Talab, Purwa Falls, Baghela Museum / Rewa Fort
- Google Maps open buttons
- WhatsApp booking
- Call and email
- Hidden owner-access test screen (tap the top header 5 times)

## Cloud APK build
GitHub Actions workflow at `.github/workflows/android-build.yml` builds a debug test APK and uploads it as an artifact named `Kamna-Tour-Travel-debug-apk`.

> This is a debug test build. Play Store production still needs secure owner authentication/backend, privacy policy, app signing, final AAB, and Play Console testing/review.
